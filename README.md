# DocuRedactor downloads

This repo only hosts the installers for **DocuRedactor – Offline Document Anonymizer**, a Windows app that takes client names, addresses, ID numbers and account numbers out of PDFs, Word/Excel files and scans before you hand them to an AI tool, and puts them back afterwards. All the processing happens on your own machine.

Easiest way to get it: **[docuredactor.com](https://docuredactor.com)**. The download buttons there always point at the latest release here.

| File | What it is |
|---|---|
| `DocuRedactor_Setup_<version>.exe` | Full installer, built-in AI model included (~1.2 GB) |
| `DocuRedactor_Update_<version>.exe` | Update for an existing install (~108 MB) |

Needs Windows 10 or 11 (64-bit). The installers aren't code-signed yet, so SmartScreen may warn you: click **More info → Run anyway**.
